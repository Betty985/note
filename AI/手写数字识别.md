学习总结：手写数字识别与卷积神经网络
1. 手写板的实现

通过 tkinter 创建手写板，可以用鼠标画数字并保存为图片。
将图片缩放到 28 × 28 的灰度图以适配神经网络的输入。
2. 数据预处理和加载

用 torchvision 加载 MNIST 数据集，并将图片数据转换成 tensor。
理解 batch_size 是每次训练输入的图片数，shuffle=True 可以打乱训练数据顺序，提高模型的泛化能力。
3. 卷积神经网络的结构

CNN 结构包括卷积层、池化层和全连接层。
卷积层：利用卷积核提取局部特征。
池化层：降低特征图的尺寸，提取主要信息。
全连接层：将提取的特征整合并输出分类结果。
4. CNN 的实现与特征可视化

使用 PyTorch 建立简单 CNN 实现手写数字识别。
获取并可视化每一层的特征图，理解CNN如何逐层提取特征。
将最终输出理解为 10 个数字类别的得分。
5. 模型训练与评估

使用损失函数（交叉熵）和优化器（SGD）训练模型。
保存训练好的模型参数，并加载进行预测。
理解未训练模型的随机输出，如何通过训练提高准确性。

使用 Matplotlib 展示每层特征图和最终分类得分。

class DrawPad(tk.Canvas):
    def __init__(self, master=None, **kwargs):
        super().__init__(master, **kwargs)
        self.old_x = None
        self.old_y = None
        self.width = 280
        self.height = 280
        self.image = Image.new("L", (self.width, self.height), color=255)
        self.draw = ImageDraw.Draw(self.image)
        self.bind('<B1-Motion>', self.paint)
        self.bind('<ButtonRelease-1>', self.reset)

    def paint(self, event):
        if self.old_x and self.old_y:
            self.create_line(self.old_x, self.old_y, event.x, event.y, width=20, fill='black', capstyle=tk.ROUND, smooth=tk.TRUE)
            self.draw.line([self.old_x, self.old_y, event.x, event.y], fill=0, width=20)
        self.old_x = event.x
        self.old_y = event.y

    def reset(self, event):
        self.old_x = None
        self.old_y = None

    def save(self, filename="digit.png"):
        img = self.image.resize((28, 28))
        img.save(filename)

import torch
from torchvision import datasets, transforms
from torch.utils.data import DataLoader
import torch.nn as nn
import torch.nn.functional as F
from PIL import Image
import matplotlib.pyplot as plt
import numpy as np

# 定义数据预处理：把图片转为Tensor，并且把像素值缩放到0~1之间
# 加载图片
img = Image.open('digit.png').convert('L')

# 转换为Tensor，并归一化到[0,1]
transform = transforms.Compose([
    transforms.ToTensor(),  # 变成 [C, H, W]，值在[0,1]
])
img_tensor = transform(img)  # 形状是 [1, 28, 28]

# 增加 batch 维度，变成 [1, 1, 28, 28]
# batch_size 表示“每次送进网络的图片数量”。
img_tensor = img_tensor.unsqueeze(0)
print(img_tensor.shape) 

# 下载并加载训练集和测试集
train_dataset = datasets.MNIST(root='./data', train=True, transform=transform, download=True)
test_dataset = datasets.MNIST(root='./data', train=False, transform=transform, download=True)

# 用 DataLoader 打包数据，方便后面训练时批量读取
# batch_size是每次喂给神经网络训练的“图片数量”
# shuffle=True：每次训练的时候，把图片顺序随机打乱
train_loader = DataLoader(train_dataset, batch_size=64, shuffle=True)
test_loader = DataLoader(test_dataset, batch_size=64, shuffle=False)

class SimpleCNN(nn.Module):
    def __init__(self):
        super(SimpleCNN, self).__init__()
        # 第一层卷积：输入1个通道（灰度图），输出16个通道，卷积核3x3
        self.conv1 = nn.Conv2d(1, 16, kernel_size=3, padding=1)
        # 第二层卷积：输入16个通道，输出32个通道
        self.conv2 = nn.Conv2d(16, 32, kernel_size=3, padding=1)
        # 池化层
        self.pool = nn.MaxPool2d(2, 2)
        # 全连接层：32*7*7 到 10
        self.fc1 = nn.Linear(32 * 7 * 7, 10)

    def forward(self, x):
        x1 = self.pool(F.relu(self.conv1(x)))  # 卷积 -> 激活 -> 池化
        x2 = self.pool(F.relu(self.conv2(x1)))  # 卷积 -> 激活 -> 池化
        x3 = x2.view(-1, 32 * 7 * 7)            # 展平成一维
        x4 = self.fc1(x3)                       # 全连接层
        return x1, x2, x4
# 初始化模型 → 图片送进模型 → 获取特征 → 可视化
model = SimpleCNN()
model.eval()
with torch.no_grad():
    feat1, feat2, output = model(img_tensor)

# 用 matplotlib 把卷积层输出的 feature map 显示出来
# feat1 形状是 [1, 16, 14, 14]，取第一个batch
features = feat1[0]

plt.figure(figsize=(10, 6))
for i in range(16):
    plt.subplot(2, 8, i+1)
    plt.imshow(features[i].cpu().numpy(), cmap='gray')
    plt.axis('off')
plt.suptitle('Feature Maps of Layer 1')
plt.show()

# 可视化第二层卷积池化后的特征图
features2 = feat2[0]  # shape: [32, 7, 7]

plt.figure(figsize=(12, 8))
for i in range(32):
    plt.subplot(4, 8, i+1)
    plt.imshow(features2[i].cpu().numpy(), cmap='gray')
    plt.axis('off')
plt.suptitle('Feature Maps of Layer 2')
plt.show()

# 看全连接层的输出
out_np = output.cpu().numpy().flatten()
plt.figure()
plt.bar(np.arange(10), out_np)
plt.xlabel('数字类别')
plt.ylabel('得分')
plt.title('Fully Connected Layer Output')
plt.show()
